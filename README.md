# 狗屎市场

我们在全球管理了8万亿美元资产，甚至在尼日尔市场都获得了丰厚的回报，唯独在A股这个屎一般的市场亏了。

每次当我们建仓完毕，就会有大量的股票突然砸下来，然后我们被迫做t，在多次做t以后，好不容易摊平了成本，以为终于稳定了局面，没想到这个时候，又有大量的预料不到的，不知从哪里出来的股票源源不断的抛出，感觉我们根本买不完！


## 原理

十一档累计跌幅，从上到下是跌超 16% 到跌超 6%。

灰色柱是历史基底，长度按家数比例、沿中轴对齐。数字已经算好，写在 `cache/baselines.json`。

虚线是历次股灾的包络。每一段日期里，各档分别取最大家数，再乘 0.9，连成一条平滑虚线，日期只标到月份。15 分钟线盖满每个交易日的段，用 15 分钟收盘相对昨收；盖不满的段改用日线收盘，日期牌上写「日线」，并且不参与灰色柱的取最大。

彩色柱是现在的家数，嵌在灰柱里，从浅跌的绿到深跌的红。实时数可以长过灰柱。柱和虚线是半透明的，好让后面的图透出来。文字和悬停条不透明。悬停某条虚线时，读的是该段跌超 6% 曾经达到的最大家数。

实时行情只连 `config.yaml` 里的一台标准行情服务器，四条连接同时分页。不探测别的地址，不连扩展行情。第一笔回来之前，界面盖着灰色蒙板，转圈显示「数据获取中」。之后每 2 分钟刷新一次。
